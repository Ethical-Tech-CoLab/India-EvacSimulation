# Decision-model recommendation: preserve the uncertainty experiment

Date: 2026-10-11. Public-source proposal.
Reviewed [README](https://github.com/Ethical-Tech-CoLab/India-EvacSimulation/blob/b6e99d8d4d3e54ede2483503d6f299059096b75e/README.md).
Assessment is documentation-led, not a validation of real evacuation outcomes.

## No runtime model replacement

This is a seeded, synthetic research instrument with explicit readiness,
Monte Carlo and assignment behavior. Security, authority consent and
willingness are non-substitutable gates. Unknown assessment and confirmed
refusal are deliberately distinct.

Do not replace factors, success distributions or assignments with Jev,
Microsoft-Decision-1 or Sage. Model uncertainty is not the experiment's field
uncertainty, and a model cannot infer consent or turn refusal into a remediable
information gap.

## Optional research-side task

After runs are sealed, assess whether public evidence supports a documented
assumption under its stated population/conditions. Use supports / partially
supports / not established / insufficient evidence, with exact source spans.
This is a derived annotation, not an input to the engine.

Compare a human checklist and deterministic checks with a local classifier or
approved hosted decision model. Jev's
[citation pattern](https://docs.typesafe.ai/cookbooks/citation_check.md)
is a starting recipe, not evidence of scientifically valid behavioral inference.

## Evaluation and gate

Split by study/assumption and run family. Measure false reassurance,
missing-evidence recall, calibration, disagreement and reviewer time/cost.
Retain all seeded regression outputs exactly; no changes to gatekeepers,
unknown/refusal semantics, published formulas or downstream mirror behavior.

Default to no new dependency. A local model requires separate licensing and
hardware testing; exact proprietary checkpoints are unavailable locally.
No operational advice, person-prioritization or measured saving is proposed.
